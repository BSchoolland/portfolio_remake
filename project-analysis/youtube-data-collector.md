- **Project Name:** YouTube Data Collector
- **What it does:** A full-stack social media analytics platform that scrapes YouTube and Instagram channels, collects video/post data, and uses AI (OpenAI/Instructor) to infer topic hashtags from transcriptions and suggest similar channels. It features a rich Next.js dashboard with topic relationship graphs (D3 force graphs), engagement scoring, viral video detection, workspace management, Google Drive integration, and audio transcription pipelines -- all containerized with Docker.
- **Coolness factor:** 8/10 -- This is a genuinely sophisticated tool that combines web scraping, AI-powered content analysis, graph-based topic modeling, and a polished React dashboard. The multi-workspace architecture, job queue system, and integration of multiple APIs (YouTube Data API, Apify for Instagram, OpenAI, Google Drive, Mailgun) show strong systems thinking.
- **Skills/technologies used:** JavaScript, Node.js, Express.js, SQL (SQLite/better-sqlite3), AI (OpenAI API, Instructor for structured outputs, Zod schemas), Next.js, React, TypeScript, Docker, D3.js, Tailwind CSS, Radix UI, Recharts, Google APIs (YouTube Data API v3, Google Drive), Apify (Instagram scraping), Mailgun (email), REST API design
