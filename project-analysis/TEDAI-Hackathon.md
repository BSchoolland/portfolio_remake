# TEDAI-Hackathon

## What it does
A proactive AI agent that continuously monitors a user's screen via screenshots, analyzes what they are doing using Google Gemini's vision capabilities, and offers smart suggestions and actionable tasks like drafting emails and creating calendar events. It includes a live chat interface with persistent session memory, a Chrome extension, voice input/output via speech-to-text, and a Python-based hotkey-driven screenshot monitor.

## Coolness factor: 8/10
This is a genuinely ambitious hackathon project that combines screen monitoring, AI vision analysis, tool-use (email/calendar creation), voice interaction, and a chat interface into a cohesive proactive assistant. The multi-component architecture (Node.js backend, React frontend, Chrome extension, Python screen capture, speech services) shows strong full-stack and systems-integration skills.
