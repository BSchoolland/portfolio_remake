Blade

I've always loved making games, and after Wrecking Wheels and Sketchy Towers I wanted to try something more polished. Blade is a top-down action game where you fight through waves of enemies and boss battles using sword combat, dashing, and upgrades. The whole thing runs in the browser, and I'd say it's my most fun game by far — the combat feels really dynamic.

I built it in TypeScript using PixiJS for rendering and Matter.js for physics. While Wrecking Wheels is still the bigger project, Blade is a lot more polished — and I think it really shows how much I've grown as a developer since then. I also leaned heavily on AI development tools this time around, which let me move way faster than I could have with Wrecking Wheels.

Each of the 4 bosses has its own AI and attack patterns, and there are over 10 different enemy types across 14+ hand-designed waves. It also works with keyboard/mouse, gamepad controllers, and mobile touch controls — getting the auto-aim system to feel good on mobile took a lot of iteration.

Key Learnings:

  • TypeScript for games: This was my first big TypeScript project, and going back to plain JavaScript afterwards felt painful. Type safety caught so many bugs during development.
  • AI-assisted development: Using AI tools throughout the process made a huge difference in how fast I could ship. It's a very different workflow compared to how I built Wrecking Wheels.
  • Cross-platform input: Supporting keyboard, gamepad, and touch all at once is surprisingly tricky. Each has its own quirks.
